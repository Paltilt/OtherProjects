# Welcome to My Project Collection!

Thanks for stopping by! This repository brings together some selected projects and works from larger collaborations. I hope it gives you a feel for how I approach problems, and what I've contributed to the projects I've worked on.

The shown projects in here are mostly smaller in size or presentations for larger projects which I can not share as some of them use third-party assets that I don't have the rights to redistribute, so I can't upload them in full. If I can not share the source code, the project folders provide descriptions, details about my contributions, and links to showcases or playable builds where available. Depending on what's included, a project may not run directly from this repository.

The number of projects shown off in here may still grow as I am currently still in the process of working on projects and preparing them for upload. 

`Please also keep in mind, that I have to use Git LFS for larger files on GitHub, which means that most of the .zip files are not going to work if you download the repository as a ZIP-file.`

## Take a Look Around

As you can probably see most of my projects have some kind of visual component. This is because when teaching myself something new I really like getting visual feedback but generally speaking the most fun part for me personally is to learn something new.
